# SQLite JDBC

Driver: `org.xerial:sqlite-jdbc:3.53.4.0`. JAR đã có sẵn, không cần tải khi chạy.

Nguồn chính thức: https://github.com/xerial/sqlite-jdbc

Tải từ Maven Central: https://repo.maven.apache.org/maven2/org/xerial/sqlite-jdbc/3.53.4.0/

Đã so sánh SHA-256 của JAR với file `.sha256` tại cùng nguồn. License của driver/native SQLite được đóng gói trong JAR; dự án driver công bố Apache License 2.0 và BSD 2-Clause.
